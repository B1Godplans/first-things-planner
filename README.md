# First Things Planner

A private daily, weekly and life-vision planner for iPad.

- Everything you write is stored only on your iPad. The app never sends entries anywhere.
- Works offline after the first visit.
- Install: open the link in Safari on the iPad, tap Share, then **Add to Home Screen**.
- Back up from **Growth → Save a backup** (save the file to iCloud Drive).

This repository holds only the app's code, never your entries.
